Switched Capacitor DC-DC Converters: Charge Transfer Analysis¶

Charge Flow Analysis¶

(Seeman and Sanders, 2008)

Voltage Conversion Ratio

Consider switched-capacitor DC-DC converter as a set of linear circuit elements in networks switched periodically.

Analyze charge flow through components in each phase and across the converter phases.

Represent charge flow as vectors so linear algebra can be applied.

Define $q_i^{(j)}$ as net charge flow through $i$th component in the $j$th converter phase.

Define $\vec{a}_c^{(j)}$ as charge transfer vector for capacitors and voltage sources in the $j$th phase (one vector defined for each phase). Usually normalized so analysis is load-independent.

Subscript $c$ in $\vec{a}_c^{(j)}$ refers to capacitors.

Ex: Arbitrary two-phase converter

  • $N$ intermediate/flying capacitors
  • One input voltage source
  • One output voltage source $\leftarrow$ models ideal steady-state output voltage at load
$$\vec{a}_c^{(1)} \equiv \left[ q_{OUT}^{(1)} \quad q_1^{(1)} \quad \dots \quad q_N^{(1)} \quad q_{IN}^{(1)} \right] / q_{OUT}$$$$\vec{a}_c^{(2)} \equiv \left[ q_{OUT}^{(2)} \quad q_1^{(2)} \quad \dots \quad q_N^{(2)} \quad q_{IN}^{(2)} \right] / q_{OUT}$$

Normalize charge transfer vectors to $q_{OUT} = q_{OUT}^{(1)} + q_{OUT}^{(2)}$, the total charge delivered to the output over a conversion cycle.

Approach: write $q_i^{(j)}$ from inspection (!) using the following assumptions:

  • Assume output voltage ripple is negligible. ($C_{OUT} \gg C_i$ such that $C_L$ acts as a voltage source and can be replaced by a voltage source for purposes of circuit analysis.)
  • In steady-state, sum of charge flow vector elements across phases is 0 coulombs for each $C_i$.

Ex: $q_1^{(1)} + q_1^{(2)} = 0$, therefore $q_1^{(1)} = -q_1^{(2)}$

  • Develop expressions by writing KCL equations at each node while alternating phases.

  • In each phase, KCL holds $\Rightarrow$ the sum of the charge transfer vector elements at each circuit node is 0.

  • Conservation of Energy: Energy from input source = Energy into output source

$$-q_{IN} V_{IN} = q_{OUT} V_{OUT}$$$$\frac{V_{OUT}}{V_{IN}} = \frac{-q_{IN}}{q_{OUT}}$$

Tip: Assign charge transfer elements from input to output or output to input, alternating across the phases.

Examples:

Applications of charge flow analysis to some simple converter topologies is presented below.

2:1 Series-Parallel Down Converter

Phase 1 (series)

(1) $q_{OUT}^{(1)} = q_x$

(2) $q_1^{(1)} = q_x$

(3) $q_{IN}^{(1)} = -q_x$

Phase 2 (parallel)

(1) $q_1^{(2)} = -q_x$

(2) $q_{OUT}^{(2)} = q_x$

(3) $q_{IN}^{(2)} = 0$

$$q_{OUT} = q_{OUT}^{(1)} + q_{OUT}^{(2)} = 2q_x \quad\quad\quad q_{IN} = q_{IN}^{(1)} + q_{IN}^{(2)} = -q_x$$$$\vec{a}_c^1 = \left[ q_x \quad q_x \quad -q_x \right] / q_{OUT} = \left[ \frac{1}{2} \quad \frac{1}{2} \quad -\frac{1}{2} \right]$$$$\vec{a}_c^2 = \left[ q_x \quad -q_x \quad 0 \right] / q_{OUT} = \left[ \frac{1}{2} \quad -\frac{1}{2} \quad 0\right]$$

Conversion ratio = ratio of net charge transferred from input to output:

$$\frac{-q_{IN}}{q_{OUT}} = \frac{-(-q_x)}{q_{OUT}} = \frac{1}{2} \checkmark \quad = \frac{-(q_{IN}^{(1)} + q_{IN}^{(2)})}{q_{OUT}^{(1)} + q_{OUT}^{(2)}} = \frac{-(-\frac{1}{2} + 0)}{\frac{1}{2} + \frac{1}{2}} = \frac{1}{2} \checkmark$$

1:1 Converter

Phase 1

Applying KCL to all branches:

(1) $$q_{IN}^{(1)} = -q_x$$

(2) $$q_1^{(1)} = q_x$$

(3) $$q_{OUT}^{(1)} = q_y$$

(4) $$q_2^{(1)} = -q_y$$

Phase 2

(1) $$q_{IN}^{(2)} = 0$$

(2) $$q_1^{(2)} = -q_x$$

(3) $$q_2^{(2)} = q_y$$

(4) $$q_{OUT}^{(2)} = q_x - q_y$$

$$q_{OUT} = q_{OUT}^{(1)} + q_{OUT}^{(2)} = q_y + (q_x - q_y) = q_x$$$$q_{IN} = q_{IN}^{(1)} + q_{IN}^{(2)} = -q_x$$$$\vec{a}_c^1 = \left[ q_y \quad q_x \quad -q_y \quad -q_x \right] / q_x = \left[ q_y/q_x \quad 1 \quad -q_y/q_x \quad -1 \right]$$$$\vec{a}_c^2 = \left[ q_x-q_y \quad -q_x \quad q_y \quad 0 \right] / q_x = \left[ \frac{q_x-q_y}{q_x} \quad -1 \quad \frac{q_y}{q_x} \quad 0 \right] = \left[ 1-\frac{q_y}{q_x} \quad -1 \quad \frac{q_y}{q_x} \quad 0 \right]$$

Conversion Ratio

$$\quad \frac{-q_{IN}}{q_{OUT}} = \frac{-(-1)}{\frac{q_y}{q_x} + \frac{q_x-q_y}{q_x}} = \frac{1}{1} = 1 \checkmark$$

1:2 Up Converter

Phase 1

(1) $$q_{IN}^{(1)} = -q_x$$

(2) $$q_1^{(1)} = q_x$$

(3) $$q_{OUT}^{(1)} = q_y$$

(4) $$q_2^{(1)} = -q_y$$

Phase 2

(1) $$q_1^{(2)} = -q_x$$

(2) $$q_2^{(2)} = +q_y$$

(3) $$q_{IN}^{(2)} = -q_x$$

(4) $$q_{OUT}^{(2)} = q_x - q_y$$

$$q_{OUT} = q_y + (q_x - q_y) = q_x$$

$$q_{IN} = -q_x + (-q_x) = -2q_x$$$$\vec{a}_c^1 = \left[ q_y \quad q_x \quad -q_y \quad -q_x \right] / q_x = \left[ \frac{q_y}{q_x} \quad 1 \quad -\frac{q_y}{q_x} \quad -1 \right]$$$$\vec{a}_c^2 = \left[ q_x - q_y \quad -q_x \quad q_y \quad -q_x \right] / q_x = \left[ 1 - \frac{q_y}{q_x} \quad -1 \quad \frac{q_y}{q_x} \quad -1 \right]$$

Conversion Ratio

$$\frac{-q_{IN}}{q_{OUT}} = \frac{-(-1 + -1)}{\frac{q_y}{q_x} + 1 - \frac{q_y}{q_x}} = \frac{2}{1} \checkmark$$

OUTPUT IMPEDANCE¶

Slow Switching Limit

Assume capacitor voltages reach final values, i.e. RC time constants $\ll$ switching period T.

Tellegen's Theorem: Consider an arbitrary network of lumped elements whose graph representation G has b branches and $n_t$ nodes.

Suppose we assign to each branch:

  1. branch potential difference $W_k$

  2. branch current $F_k$

for $k = 1, 2, \dots, b$

If, branch potential differences $W_1, W_2, \dots, W_b$ satisfy KVL and, branch currents $F_1, F_2, \dots, F_b$ satisfy KCL

then dot product $\vec{W} \cdot \vec{F} = \sum_{k=1}^{b} W_k F_k = 0$, i.e. $\vec{W}$ and $\vec{F}$ are orthogonal.

Basically, theorem restates conservation of energy, i.e. all dissipated power must be delivered by sources in the network.

(Note: theorem applies to fluid networks, biological networks, etc. in addition to electrical circuits)

Application to switched capacitor charge transfer analysis $\rightarrow$ apply a test source $v_{out}$ at output, determine the current $i_{out}$, and calculate the output impedance $R_o = \frac{v_{out}}{i_{out}}$.

Consider an arbitrary two phase converter. Each phase corresponds to a different network.

$$\vec{F} \equiv \text{charge transfer vector} \equiv \vec{a}_c^{(1)} = \left[ q_{OUT}^{(1)} \quad q_1^{(1)} \quad \dots \quad q_N^{(1)} \quad q_{IN}^{(1)} \right] / q_{OUT}$$$$\vec{a}_c^{(1)} = \left[ a_{OUT}^{(1)} \quad a_{c,1}^{(1)} \dots a_{c,N}^{(1)} \quad a_{IN}^{(1)} \right]$$$$\vec{W} \equiv \text{voltage vector} \equiv \vec{v}_c^{(1)} = \left[ v_{OUT} \quad v_{c,1}^{(1)} \quad \dots \quad v_{c,N}^{(1)} \quad v_{IN} \right]$$

Define $\vec{a}_c^{(2)} , \vec{v}_c^{(2)}$ similarly for second phase.

By Tellegen's Theorem, dot product of charge transfer and voltage vectors should equal zero:

$$\vec{a}_c^{(1)} \cdot \vec{v}_c^{(1)} + \vec{a}_c^{(2)} \cdot \vec{v}_c^{(2)} = 0 = v_{OUT} (a_{OUT}^{(1)} + a_{OUT}^{(2)}) + \sum_{i=1}^N (a_{c,i}^{(1)} v_{c,i}^{(1)} + a_{c,i}^{(2)} v_{c,i}^{(2)}) + v_{IN} (a_{IN}^{(1)} + a_{IN}^{(2)}) = 0$$

To find output impedance, first eliminate independent sources $\Rightarrow v_{IN} = 0$

$a_{OUT}^{(1)} + a_{OUT}^{(2)} = 1 \quad$ (vector elements normalized to $q_{OUT}$)

$a_{c,i}^{(1)} = -a_{c,i}^{(2)} \quad$ (zero net charge transferred into/out of $C_i$'s during conversion cycle)

Define $a_{c,i} \equiv a_{c,i}^{(1)} = -a_{c,i}^{(2)} \quad$ and define $q_i = a_{c,i} q_{OUT}$

Therefore, dot product becomes

$$\quad v_{OUT} + \sum_{i=1}^N a_{c,i} \underbrace{(v_{c,i}^{(1)} - v_{c,i}^{(2)})}_{\Delta v_i} = 0$$$$\Rightarrow \quad\quad v_{OUT} + \sum_{i=1}^N a_{c,i} \Delta v_i = 0$$

Multiplying both sides by $q_{OUT}$,

$$\quad v_{OUT} \cdot q_{OUT} + \sum_{i=1}^N a_{c,i} \Delta v_i q_{OUT} = 0$$$$\Rightarrow \quad\quad v_{OUT} q_{OUT} + \sum_{i=1}^N \Delta v_i q_i = 0$$

Assuming linear capacitors,

$$\Delta v_i = \frac{q_i}{C_i} \Rightarrow v_{OUT} q_{OUT} + \sum_{i=1}^N \frac{q_i^2}{C_i} = 0$$

Divide both sides by $q_{OUT}^2$,

$$\quad \frac{v_{OUT}}{q_{OUT}} + \sum_{i=1}^N \left(\frac{q_i}{q_{OUT}}\right)^2 \frac{1}{C_i} = 0$$$$i_{OUT} = \frac{q_{OUT}}{\underset{\text{switching period}}{T}} = q_{OUT} \cdot \underset{\text{switching frequency}}{f_{sw}} \quad\text{, so divide both sides by } f_{sw}:$$$$\frac{v_{OUT}}{q_{OUT} f_{sw}} + \sum_{i=1}^N \left(\frac{q_i}{q_{OUT}}\right)^2 \frac{1}{C_i f_{sw}} = 0 \Rightarrow \frac{v_{OUT}}{\underset{\text{current looking into circuit}}{-i_{OUT}}} = \sum_{i=1}^N \frac{a_{c,i}^2}{C_i f_{sw}}$$

Slow Switching Limit Output Impedance $\quad R_{SSL} = \sum_{i=1}^N \frac{a_{c,i}^2}{C_i f_{sw}}$

Ex: 1:2 up converter

$a_{c,i} = a_{c,1} = 1$

$C_i = C_{fly} \quad\quad \Big\} R_{SSL} = \frac{1}{C_{fly} f_{sw}}$

Fast Switching Limit

Assume M switches in the converter.

$R_i \equiv$ resistance of $i$th switch

Average current through each switch is charge transferred across the switch divided by conduction time (i.e., duration/fraction of period switch conducts):

$$i_{R,i} = \frac{q_{r,i}}{\underset{\text{duty cycle}}{D}T} = \frac{q_{r,i}f_{sw}}{D}$$

Define charge flows similar to capacitors:

$$q_{r,i} = a_{r,i} q_{OUT}$$

$$i_{OUT} = q_{OUT} f_{sw} \Rightarrow q_{OUT} = \frac{i_{OUT}}{f_{sw}}$$

For simplicity, assume $D = 0.5$, therefore $i_{r,i} = 2 a_{r,i} i_{OUT}$

$$P_{loss} \text{ (switches)} = \sum_{i=1}^M i_{r,i}^2 R_i \underset{\substack{\uparrow \\ \text{assumes all} \\ \text{switches on for} \\ \text{50\% duty cycle}}}{D} \quad\quad = \sum_{i=1}^M \frac{1}{2} R_i (2 a_{r,i} i_{OUT})^2$$$$\text{Define } \underset{\substack{\nearrow \\ \text{fast} \\ \text{switching} \\ \text{limit}}}{R_{FSL}} = \frac{P_{loss} \text{ (switches)}}{i_{OUT}^2} = 2 \sum_{i=1}^M R_i a_{r,i}^2 \equiv \text{output impedance if switch loss dominates capacitor charge transfer losses}$$

Total Output Impedance

$$\quad\quad R_{OUT} = \sqrt{\underset{\substack{\nearrow \\ \text{decreases w/} \\ \text{switching frequency}}}{R_{SSL}^2} + \underset{\substack{\uparrow \\ \text{decreases w/ switch size}}}{R_{FSL}^2}}$$

# 1:2 Series-Parallel Converter Parameters
# ----------------------------------------
Cfly = 1e-12 # Fly capacitance (F)
Rsw  = 1e3   # Switch resistance (ohms)

fvec = geomspace(1.0e3, 1.0e9, 1000) # Frequency range (Hz)

# Slow-Switching Limit Output Impedance
RSSL = (1/(Cfly*fvec))

# Fast-Switching Limit Output Impedance
RFSL = 8*Rsw*ones(len(fvec))

# Total Output Impedance
Rout = sqrt( RSSL**2 + RFSL**2 )

Switched Capacitor Optimization¶

All converter losses (capacitor charge transfer and switch resistance) are reflected in real output resistance $\Rightarrow$ optimize components to minimize impedance

  • Minimal output impedance $\rightarrow$ maximum efficiency for fixed output power
  • Also maximum output power for fixed loss

(1) Optimizing capacitances $\rightarrow$ minimize SSL impedance

(2) Optimizing switch resistances $\rightarrow$ minimize FSL impedance

(3) Choose maximum operating frequency by limiting parasitic losses (e.g., dynamic power dissipation from driving switches): total capacitance and switch conductance adjusted to meet impedance goal and balance SSL and FSL impedances

SSL Capacitor Optimization

Capacitor optimization based on size/cost constraint : (1) total energy storage capability held constant, or (2) total capacitance held constant if all capacitors have same voltage rating (e.g., on-chip capacitors)

Energy constraint :

$$\sum_i \frac{1}{2} \underbrace{(v_{c,i (\text{rated})})^2}_{\substack{\text{max rated voltage} \\ \text{for ith capacitor}}} C_i = \underbrace{E_{tot}}_{\substack{\text{total capacitor energy} \\ \text{constraint}}}$$

SSL output impedance:

$$R_{SSL} = \sum_i \frac{a_{c,i}^2}{C_i f_{sw}}$$

Lagrange multipliers: optimize $R_{SSL}$ while holding $E_{tot}$ fixed

$$\mathcal{L} = \underbrace{\sum_i \frac{(a_{c,i})^2}{C_i}}_{\substack{R_{SSL} \text{ scaled by} \\ f_{sw}\text{; } f_{sw} \text{ constant} \\ \text{and doesn't affect} \\ \text{minimization}}} + \underbrace{\lambda}_{\substack{\text{Lagrange} \\ \text{multiplier}}} \underbrace{\left( \sum_i \frac{1}{2} (v_{c,i (\text{rated})})^2 C_i - E_{tot} \right)}_{\text{energy constraint}} \quad\quad \text{Lagrangian}$$
$$\nabla \mathcal{L}(C_i, \lambda) = 0 \quad \Rightarrow \quad \frac{\partial \mathcal{L}}{\partial C_i} = - \frac{(a_{c,i})^2}{C_i^2} + \lambda \frac{1}{2} (v_{c,i(\text{rated})})^2 = 0$$$$\frac{\partial \mathcal{L}}{\partial \lambda} = \sum_i \frac{1}{2} (v_{c,i(\text{rated})})^2 C_i - E_{tot} = 0$$

Solving:

$$\quad C_i^2 = \frac{(a_{c,i})^2}{\frac{\lambda}{2} (v_{c,i(\text{rated})})^2} \quad \Rightarrow C_i = \sqrt{\frac{2}{\lambda}} \frac{\vert{}a_{c,i}\vert{}}{\vert{}v_{c,i(\text{rated})}\vert{}}$$$$\sum_i \frac{1}{2} (v_{c,i(\text{rated})})^2 \sqrt{\frac{2}{\lambda}} \frac{\vert{}a_{c,i}\vert{}}{\vert{}v_{c,i(\text{rated})}\vert{}} = E_{tot} \quad \Rightarrow \sqrt{\frac{2}{\lambda}} = \frac{2 E_{tot}}{\sum_i \vert{}a_{c,i} v_{c,i(\text{rated})}\vert{}}$$

Optimal $C_i$ is

$$C_i^* = \frac{\vert{}a_{c,i}\vert{}}{\vert{}v_{c,i(\text{rated})}\vert{}} \frac{2 E_{tot}}{\sum_k \vert{}a_{c,k} v_{c,k(\text{rated})}\vert{}}$$

Optimal capacitor energy $E_i$ is

$$E_i = \frac{1}{2} C_i (v_{c,i(\text{rated})})^2 = \frac{\vert{}a_{c,i} v_{c,i(\text{rated})}\vert{}}{\sum_k \vert{}a_{c,k} v_{c,k(\text{rated})}\vert{}} \cdot E_{tot}$$

Optimal capacitance proportional to charge flow ($a_{c,i}$) and inversely proportional to rated voltage: bigger charge flow $\Rightarrow$ bigger cap Optimal energy storage proportional to charge flow-voltage (Q-V) product.

Optimal SSL impedance: $\quad R_{SSL}^* = \frac{1}{2 E_{tot} f_{sw}} \left( \sum_i \vert{}a_{c,i} v_{c,i(\text{rated})}\vert{} \right)^2$

Special case: all capacitors have same voltage rating so constrain total capacitance $C_{tot}$ instead of total energy.

$$C_i^* = \frac{\vert{}a_{c,i}\vert{}}{\sum_k \vert{}a_{c,k}\vert{}} C_{tot} \quad\quad\quad \begin{array}{l} \text{optimal capacitance proportional to its charge} \\ \text{flow divided by total charge flows } \Rightarrow \text{sets voltage} \\ \text{ripple equal in magnitude for all capacitors.} \end{array}$$$$R_{SSL}^* = \frac{1}{C_{tot} f_{sw}} \left( \sum_i \vert{}a_{c,i}\vert{} \right)^2 \quad\quad \leftarrow \text{optimized impedance for same capacitor voltage rating}$$

FSL Switch Optimization

Cost metric for integrated switches is area, but switches must be able to block maximum working voltages. Also, switches should minimize resistance (maximize conductance) to minimize $I^2R$ losses.

For MOSFET switches, $\quad A_{sw} \propto WL \quad$ FET conductance $\quad G \propto \frac{W}{L} \Rightarrow W \propto GL$

FET breakdown voltage $\quad V_{r(\text{rated})} \propto L \quad \Rightarrow \quad L \propto V_{r(\text{rated})}$

$\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad \text{(constant breakdown electric field)}$

Combining all of the above expressions, $\quad A_{sw} \propto G L \cdot L = G L^2 = G V_{r(\text{rated})}^2$

Use total switch area as constraint: $\quad A_{tot} = \sum_{\text{all switches}} G_i (V_{r,i(\text{rated})})^2$

FSL output impedance: $R_{FSL} = 2 \sum_i R_i a_{r,i}^2$

Lagrangian $\quad \mathcal{L} = \underbrace{\sum_i \frac{(a_{r,i})^2}{G_i}}_{\substack{R_{FSL} \text{ without} \\ \text{factor of 2,} \\ \text{has no effect on} \\ \text{minimization}}} + \quad \lambda \underbrace{\left( \sum_i G_i (V_{r,i(\text{rated})})^2 - A_{tot} \right)}_{\substack{\text{total switch area} \\ \text{constraint}}}$

Taking $\nabla \mathcal{L}(G_i, \lambda)$ and solving, the optimal switch conductance is

$$G_i^* = \frac{1}{R_i^*} = \left\vert{} \frac{a_{r,i}}{V_{r,i(\text{rated})}} \right\vert{} \frac{A_{tot}}{\sum_k \vert{}a_{r,k} V_{r,k(\text{rated})}\vert{}}$$

Optimal $R_{FSL}$ obtained is:

$$\quad R_{FSL}^* = \frac{2}{A_{tot}} \left( \sum_i \vert{}a_{r,i} V_{r,i(\text{rated})}\vert{} \right)^2$$

Special case: all switches have same voltage rating so total conductance can be constrained instead of area.

$$G_i^* = \frac{\vert{}a_{r,i}\vert{}}{\sum_k \vert{}a_{r,k}\vert{}} G_{tot} \quad\quad \begin{array}{l} \text{Optimal conductance proportional to charge flow} \\ \text{divided by total switch charge flow.} \end{array}$$$$R_{FSL}^* = \frac{2}{G_{tot}} \left( \sum_i \vert{}a_{r,i}\vert{} \right)^2$$
